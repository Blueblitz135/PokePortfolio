# Ticket 007 - Graded Card Overlay

## Goal

Show graded cards with a code-based slab/grade overlay.

## Requirements

- Use card image as base.
- Render a slab-like container in React/CSS.
- Show grading company.
- Show grade.
- Show optional card name/card number in label.

## Rules

- Do not generate permanent image files.
- Do not require a real graded slab photo.
- Keep it CSS/HTML for MVP.

## Acceptance criteria

- Graded card asset displays differently from raw card asset.
- PSA 10/BGS 9.5/CGC examples look reasonable.
- Missing image still works with placeholder.
